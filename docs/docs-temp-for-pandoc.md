基本的な要素の対応は以下の通りです。
Word側でこれらのスタイルをカスタマイズ（右クリック ＞ 変更）することで、見た目を一括制御できます。

### 基本要素の対応表

| Markdown 要素 | Word スタイル名 (日本語版) | Word Style Name (Internal) |
| :--- | :--- | :--- |
| `# Heading` | **見出し 1** | `Heading 1` |
| `## Heading` | **見出し 2** | `Heading 2` |
| (通常の段落) | **標準** または **本文** | `Normal` / `Body Text` |
| `* item` (箇条書き) | **リスト段落** | `List Bullet` |
| `1. item` (番号付き) | **リスト段落** | `List Number` |
| `> quote` (引用) | **引用** | `Block Text` |
| `---` (水平線) | **Horizontal Rule** | `Horizontal Rule` |

---

### 特殊な要素・書式の対応

| 書式・要素 | 適用されるスタイル / 挙動 |
| :--- | :--- |
| **太字** / *斜体* | 特定のスタイルではなく、Wordの「文字書式」として適用されます。 |
| `code` (インライン) | **Verbatim Char** スタイルが適用されます。 |
| ` ``` ` (コードブロック) | **Source Code** スタイルが適用されます。 |
| 画像のキャプション | **Image Caption** スタイルが適用されます。 |
| 表 (Table) | **Table** スタイル。ただし、Wordの「表のスタイル」として制御されます。 |
| 脚注 | **脚注文** (`Footnote Text`) スタイル。 |

---

### 注意点とTips

* **「標準」スタイルの重要性:**
    Wordでは多くのスタイルが「標準 (Normal)」スタイルを継承しています。
    フォントや行間をドキュメント全体で統一したい場合は、まず**「標準」スタイル**のフォント（日本語用・英数字用）と段落設定（行間）を変更してください。
* **スタイルが見当たらない場合:**
    `--print-default-data-file` で書き出した直後のファイルには、まだすべてのスタイルが表示されていないことがあります。
    その場合は、Wordのスタイルパネルのオプションで「使用中のスタイル」から「すべてのスタイル」に変更して探してみてください。
* **コードブロックのフォント:**
    等幅フォントにしたい場合は、`Source Code` スタイルのフォントを
     `Courier New` や `Consolas` などに変更しておくと、エンジニアらしい読みやすいドキュメントになります。
